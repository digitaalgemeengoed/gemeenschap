## Waarom de EUPL

De European Union Public Licence is een open source licentie van de Europese Commissie, in alle officiële talen van de EU, en geschikt voor overheden. Ze zorgt dat verbeteringen aan een gedeeld component ook weer gedeeld worden.

## Bijdragen

1. Kies een project en lees de README in de repository.
2. Kijk in [Redmine](https://projecten.digitaalgemeengoed.nl) welke meldingen en wensen er liggen.
3. Overleg bij iets groters eerst in de werkgroep Developers & contributors.
4. Stuur een pull request. Iemand anders kijkt mee voordat het wordt samengevoegd.
