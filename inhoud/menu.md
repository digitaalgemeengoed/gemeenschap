# Menu's

Elk kopje is een menu; daaronder de links, in volgorde. Een link die twee
spaties inspringt, komt in het uitklapmenu van het punt erboven. Een link
naar een pagina die nog een concept is, verschijnt pas als die pagina
gepubliceerd is.

In de voet worden de punten zonder link kolommen met de punten eronder; de
punten met een link komen in de onderste regel.
