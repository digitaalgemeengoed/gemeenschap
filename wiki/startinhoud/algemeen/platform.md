# Het platform

Op het platform komt het werk van het netwerk samen. Je logt overal in met **hetzelfde account** (het DGG-account, beheerd in Keycloak op aanmelden.digitaalgemeengoed.nl).

| Onderdeel | Adres | Waarvoor | Wie ziet het |
|---|---|---|---|
| Site | [digitaalgemeengoed.nl](https://digitaalgemeengoed.nl) | informatie, projecten, crowdfunding, dashboard voor leden | iedereen; het dashboard alleen leden |
| Fora en werkgroepen | [/forum/](https://digitaalgemeengoed.nl/forum/), [/groepen/](https://digitaalgemeengoed.nl/groepen/) | discussie, per werkveld en per project | ingelogde leden |
| Ledenoverzicht | [/leden/](https://digitaalgemeengoed.nl/leden/) | elkaar vinden | ingelogde leden (e-mailadressen nooit) |
| Projecten | [projecten.digitaalgemeengoed.nl](https://projecten.digitaalgemeengoed.nl) (Redmine) | meldingen, wensen, roadmap, fase per project | **openbaar** |
| Kennisbank | kennis.digitaalgemeengoed.nl (deze wiki) | handleidingen, ervaringen, uitleg | ingelogde leden |
| Architectuurmodellen | [architectuur.digitaalgemeengoed.nl](https://architectuur.digitaalgemeengoed.nl) | ArchiMate-modellen per project | ingelogde leden |
| Code | [github.com/digitaalgemeengoed](https://github.com/digitaalgemeengoed) | broncode, ook van de site zelf | openbaar (de kennisbank-repo is besloten) |

## Werkgroepen

Op de site zijn er werkgroepen, elk met een eigen forum: Common Ground, Open Overheid, Records Management, Projectportfolio, Developers & contributors, en Implementatie & beheer. Een nieuwe werkgroep maakt de kerngroep aan; vraag erom in het forum *Algemeen*.

## Wat waar hoort

| Je wilt… | Doe het in… |
|---|---|
| een vraag stellen of een idee bespreken | het forum (of de werkgroep) |
| een fout of wens vastleggen | Redmine, zie [Meldingen en wensen](/algemeen/meldingen-en-wensen) |
| uitleggen hoe iets werkt, of wat je hebt geleerd | deze kennisbank |
| een architectuurplaat maken of wijzigen | het model in Archi, zie [Werken in de kennisbank](/algemeen/kennisbank) |
| code of een tekst van de site verbeteren | GitHub, zie [Bijdragen](/algemeen/bijdragen) |
